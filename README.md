# Workflow

Вътрешно приложение за поръчките на екипа: ръчно въвеждане на поръчки, етапи по продукт и обобщение какво има за правене.

Приложението е един файл (`index.html`). Данните са в Supabase и са достъпни само за членове на екипа след вход.

Изходният код е в `src/app.html`. Как се билдва, тества и публикува: виж `CLAUDE.md`.
